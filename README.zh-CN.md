# 基于人工智能的虚假新闻检测

[English](README.md) | 简体中文

当今，虚假信息在各类数字平台上迅速传播，识别并遏制假新闻变得尤为重要。本项目利用**人工智能与机器学习**方法，构建了一个自动识别虚假新闻文章的系统。

## 方法概述

### 1. 文本预处理
文本数据结构复杂，直接分析难度较大。项目首先对语料进行清洗和标准化，重点采用**词干提取（Stemming）**，把单词还原为词根形式。这样既降低了词表规模，也提升了后续特征提取的效率。

### 2. 文本向量化
项目使用两种向量化方法，把文本转换为机器学习算法可以处理的数值特征：

- **Count Vectorizer（词频向量化）**：统计每个词在文档中出现的次数，生成词频矩阵。
- **TF-IDF Vectorizer**：综合考虑词在当前文档中的出现频率及其在整个语料中的稀有程度，衡量每个词的重要性。

### 3. 分类模型
采用两种适合文本分类任务的经典算法：

- **决策树（Decision Tree）**
- **朴素贝叶斯（Naive Bayes）**

### 4. 超参数调优
使用 **RandomizedSearchCV** 在超参数空间中随机搜索，寻找最优参数组合，从而提升模型准确率。

### 5. 模型评估
以**准确率（Accuracy）**作为主要评估指标，即被正确分类的样本所占比例，用来衡量系统的整体表现。
